# 산업연관표(2023) 분석 대시보드

한국은행 2023년 산업연관표 자료를 활용하는 정적 웹 대시보드입니다.

## 이번 화면 개선
- 왼쪽 분석 목차를 요약 → 원자료 탐색 → 유발계수 → 영향력·감응도계수 → 유발효과 → 최종수요 비중 → 시나리오 분석 → 분석 안내 순서로 통합
- 핵심 산업구조 지표는 기본적으로 1위 산업을 표시하고, 상위 10개·20개 버튼으로 가로 막대그래프를 확장
- 영향력·감응도 파이프라인의 굵기 차이를 더 크게 표현하고 오른쪽 끝에 전방 → 후방 방향 화살표 추가
- 최종수요 비중을 비중 내림차순 가로 막대그래프로 변경

## 실행
정적 파일을 웹 서버 또는 GitHub Pages에 배포하면 됩니다. `index.html`을 브라우저에서 직접 열 경우 브라우저 정책에 따라 Worker/데이터 로딩이 제한될 수 있으므로 로컬 웹 서버 사용을 권장합니다.

## 자료
`data/` 폴더의 2023년 산업연관표 Excel 파일을 사용합니다. 원자료 출처와 기준 연도는 각 화면에 표시됩니다.

## v4 추가 기능: 전체 평균 기준선 및 산업 간 분석
- 산업 요약의 6개 순위표에 해당 지표의 전체 산업 산술평균 기준선을 점선으로 표시합니다.
- 유발계수는 생산·수입·부가가치 지표별 전체 산업 평균을 각각 별도 기준선으로 비교합니다.
- 영향력·감응도계수는 평균 1을 기준선으로 표시합니다.
- 유발효과 히트맵 하단에 생산·수입·부가가치 유발계수의 전체 산업 평균 행을 추가합니다.
- 시나리오 결과 막대그래프와 산업별 결과표에 전체 산업 평균을 표시합니다.
- 시나리오 분석 뒤에 2~3개 산업의 유발계수·영향력·감응도계수를 비교하는 기능을 추가했습니다.
- 선택 산업을 중심으로 주요 공급 산업(후방)과 주요 수요 산업(전방)을 보여주는 연결관계도를 추가했습니다.
- 평균 기준선은 현재 선택한 산업분류(대·중·소·기본부문)의 전체 산업을 기준으로 다시 계산됩니다.
