# 산업연관분석 통합 플랫폼

2023년 기준 산업연관표를 이용해 원자료를 탐색하고 산업별 생산·수입·부가가치 유발효과를 분석하는 정적 웹앱입니다. GitHub Pages에서 실행할 수 있으며, 계산은 브라우저 안의 Pyodide(WebAssembly Python)와 Web Worker에서 수행합니다.

## 1. 주요 기능

- 2023년 산업연관표 12개 시트 탐색
- 산업분류 4종 전환: 소분류(165개), 중분류(83개), 대분류(33개), 기본부문(380개)
- 산업코드·산업명으로 행과 열 검색
- 탭 구조: 산업 찾기, 원자료 탐색, 시나리오 분석, 분석 안내
- 산업별 생산·수입·부가가치유발계수 합계와 영향력·감응도계수 핵심 지표 카드
- 영향력·감응도계수 4분면 산점도 및 선택 산업의 후방·전방 연쇄효과 비교
- 선택 산업의 생산·수입·부가가치 유발계수 히트맵
- 여러 산업의 국내 최종수요 증가 충격을 합산하는 시나리오 분석
- 산업별 생산·수입·부가가치 유발액 표 및 CSV 다운로드
- 생산·수입·부가가치 유발계수의 행렬 항등식 검증

## 2. 데이터 파일과 산업분류

`data/` 폴더에 있는 네 개의 엑셀 파일을 사용합니다.

| 웹앱 선택 | 파일 | 산업 수 |
|---|---|---:|
| 소분류 | `io-2023-small.xlsx.xlsx` | 165 |
| 중분류 | `io-2023-mid.xlsx.xlsx` | 83 |
| 대분류 | `io-2023-large.xlsx.xlsx` | 33 |
| 기본부문 | `io-2023.xlsx` | 380 |

각 엑셀 파일은 같은 2023년 기준의 12개 시트를 포함합니다.

1. `A표_총거래표(생산자)`
2. `A표_수입거래표(생산자)`
3. `A표_국산거래표(생산자)`
4. `총투입계수(A)`
5. `수입투입계수(Am)`
6. `국산투입계수(Ad)`
7. `생산유발계수`
8. `수입유발계수`
9. `부가가치유발계수`
10. `최종수요 항목별 생산유발액`
11. `최종수요 항목별 수입유발액`
12. `최종수요 항목별 부가가치유발액`

분류를 변경하면 해당 분류의 별도 엑셀 파일을 다시 읽습니다. 산업코드는 엑셀의 행·열 코드가 동시에 존재하는 부문을 기준으로 식별합니다. 서로 다른 분류의 코드 체계를 임의로 잘라 맞추지 않습니다.

## 3. 웹앱 사용 방법

### 3.1 자료 불러오기
1. 화면 맨 위의 `산업분류`에서 소분류·중분류·대분류·기본부문 중 하나를 선택합니다.
2. `자료 불러오기`를 누릅니다.
3. 상태 표시가 `준비 완료`로 바뀌면 산업 찾기 탭에서 지표와 차트를 사용할 수 있습니다.
4. 다른 분류를 선택하면 해당 분류의 파일을 새로 읽고 지표를 다시 계산합니다.

처음 실행할 때는 Pyodide와 Python 패키지(numpy, openpyxl)를 CDN에서 내려받으므로 네트워크 연결이 필요합니다.

### 3.2 산업 찾기
1. 산업명 또는 코드를 검색해 분석 산업을 선택합니다.
2. 분류 경로에는 현재 선택한 산업분류 수준과 산업명이 표시됩니다. 서로 다른 산업분류 파일 간 세부 코드의 계층 연결을 임의로 추정하지 않습니다.
3. 생산·수입·부가가치유발계수 합계는 배, 영향력·감응도계수는 평균 1을 기준으로 한 지수로 표시합니다.
4. 후방·전방 연쇄효과 막대와 4분면 산점도에서 선택 산업의 상대적 위치를 확인합니다. 산점도 점에 마우스를 올리면 산업명과 계수를 확인할 수 있습니다.
5. 상위 산업 수를 선택하고 히트맵 보기 버튼을 누르면 선택 산업의 유발계수 행렬 열을 확인할 수 있습니다.

### 3.3 원자료 탐색
1. 12개 시트 중 확인하려는 표를 선택합니다.
2. 행 산업 검색창에 산업명 또는 코드를 입력합니다.
3. 행 산업을 선택합니다.
4. 열 산업 검색창에 산업명 또는 코드를 입력해 결과를 좁힙니다.
5. `자료 단위`와 시트명을 확인하고 값을 해석합니다.

행은 공급·투입 측 산업에 해당하는 행이고, 열은 해당 표의 열 머리글에 해당합니다. 표 종류에 따라 행·열의 경제적 의미가 달라질 수 있으므로 시트명과 원자료의 행·열 제목을 함께 확인해야 합니다. 원자료의 빈 셀은 `빈 셀`로 표시합니다.

### 3.4 산업연관구조 히트맵
1. 산업명 또는 코드를 검색해 분석 산업을 선택합니다.
2. 표시할 상위 산업 수를 선택합니다.
3. `히트맵 분석`을 누릅니다.
4. 생산·수입·부가가치 유발계수의 상대적 크기를 색으로 비교합니다.

히트맵은 선택한 산업의 최종수요 변화에 대응하는 유발계수 행렬의 열을 보여줍니다. 각 열은 별도의 색상 범위를 사용하므로 서로 다른 계수 열의 색 농도를 절대 크기로 직접 비교하면 안 됩니다. 수치는 계수(배)이며, 국산 최종수요가 1백만원 증가하는 경우에는 유발액(백만원)으로 해석할 수 있습니다.

### 3.5 시나리오 분석
1. 산업을 검색해 선택합니다.
2. 국내 생산물 최종수요 증가액을 백만원 단위로 입력합니다.
3. `시나리오에 추가`를 눌러 산업별 충격을 입력합니다.
4. 여러 산업의 충격을 추가할 수 있습니다.
5. `파급효과 계산`을 누릅니다.
6. 총수요 증가액, 생산유발액, 수입유발액, 부가가치유발액과 산업별 결과를 확인합니다.
7. `전체 산업 분석 결과 CSV 다운로드`로 결과를 저장합니다.

예: 1,000백만원은 10억원입니다. 현재 구현은 양의 국내 최종수요 증가 충격을 지원합니다. 수요 감소나 수입 최종수요 충격은 이 버전의 입력 범위에 포함하지 않습니다.

## 4. 단위 및 기준

- 기준연도: 2023년
- 가격 기준: 생산자가격
- 거래표 금액: 엑셀 시트에 표시된 단위를 따르며, 제공된 거래표와 시뮬레이터 입력·출력은 백만원 기준입니다.
- 투입계수·생산유발계수·수입유발계수·부가가치유발계수: 배(계수)
- 영향력계수: 상대 지수
- 구성비: 원자료 표기에 따른 퍼센트(%)

금액과 계수는 서로 다른 차원의 지표입니다. 예를 들어 생산유발계수 1.5배는 금액 1.5백만원을 뜻하지 않습니다. 최종수요 충격액에 계수를 적용한 뒤에야 유발액(백만원)이 산출됩니다. 시트별 단위가 표시된 경우 그 표기를 우선 확인해야 합니다.

## 5. 분석 모형 및 계산 방법

### 5.1 생산유발효과

국산 투입계수행렬을 \(A^d\), 단위행렬을 \(I\), 국산 최종수요 변화 벡터를 \(\Delta Y^d\)라고 하면,

\[
\Delta X=(I-A^d)^{-1}\Delta Y^d
\]

여기서 \((I-A^d)^{-1}\)는 생산유발계수행렬입니다. 앱은 제공된 `생산유발계수` 시트를 읽어 시뮬레이션에 사용합니다.

### 5.2 수입유발효과

수입 투입계수행렬을 \(A^m\)이라 하면,

\[
\Delta M=A^m\Delta X
\]

앱은 제공된 `수입유발계수` 행렬을 사용하여 수입유발액을 계산합니다.

### 5.3 부가가치유발효과

산업별 부가가치계수를 대각행렬 \(\hat{v}\)로 나타내면,

\[
\Delta V=\hat{v}\Delta X
\]

앱은 제공된 `부가가치유발계수` 행렬을 사용합니다.

### 5.4 영향력계수

영향력계수는 산업별 생산유발계수의 열합을 전체 산업 평균과 비교한 상대 지수입니다. 앱 대시보드에서는 `생산유발계수` 시트의 `9801` 행을 사용합니다. 지수이므로 금액 단위가 없습니다.

### 5.5 감응도계수
감응도계수는 산업별 생산유발계수의 행합을 전체 산업 행합 평균과 비교한 상대 지수입니다. 앱은 생산유발계수행렬의 행합을 전체 산업 행합 평균으로 나누어 계산합니다. 지수이므로 금액 단위가 없으며 전체 산업 평균은 1입니다.

### 5.6 생산유발계수 상위 산업

생산유발계수 상위 10개는 `생산유발계수` 시트의 `9590` 행(열합)을 이용해 정렬합니다. 단위는 배입니다.

## 6. 데이터 검증

자료를 불러올 때 다음 행렬 관계의 최대 절대 잔차를 계산합니다.

- 생산유발계수: \((I-A^d)L \approx I\)
- 수입유발계수: \(A^mL \approx M\)
- 부가가치유발계수: \(\hat{v}L \approx V\)

최대 절대 잔차가 \(10^{-8}\) 미만인 경우 검증 통과로 처리합니다. 계산은 numpy의 부동소수점 연산을 사용하므로 잔차가 정확히 0이 아닌 매우 작은 값으로 나타날 수 있습니다.

## 7. 프로젝트 파일 구조

```text
444444-main/
├── index.html
├── style.css
├── app.js
├── worker.js
├── model.py
├── heatmap.js
├── README.md
├── validation-report.json
└── data/
    ├── io-2023.xlsx
    ├── io-2023-small.xlsx.xlsx
    ├── io-2023-mid.xlsx.xlsx
    └── io-2023-large.xlsx.xlsx
```

- `index.html`: 화면 구조 및 메뉴
- `style.css`: 반응형 디자인
- `app.js`: 검색, 탭 전환, 지표·산점도·히트맵 렌더링, 시뮬레이션 제어
- `worker.js`: Web Worker에서 Pyodide 실행 및 메시지 처리
- `model.py`: 엑셀 데이터 처리와 행렬 계산
- `heatmap.js`: 산업연관계수 히트맵 표시
- `data/`: 산업분류별 원자료 엑셀 파일

## 8. 실행 및 GitHub Pages 배포

### 로컬 실행
브라우저 보안 정책상 `file://`로 직접 열기보다 로컬 웹서버를 사용하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

### GitHub Pages
1. 프로젝트 파일과 `data/` 폴더를 저장소 루트에 업로드합니다.
2. GitHub 저장소의 Settings → Pages로 이동합니다.
3. 배포 소스를 `Deploy from a branch`로 선택합니다.
4. 배포 브랜치와 폴더를 지정하고 저장합니다.
5. 생성된 Pages 주소에서 웹앱을 확인합니다.

`data/`의 엑셀 파일 이름과 경로를 변경하면 `app.js`의 `FILES` 경로도 함께 수정해야 합니다.

## 9. 알려진 범위와 유의사항

- 현재 시뮬레이터는 양의 국내 최종수요 증가만 지원합니다.
- 고용·취업유발효과는 현재 데이터 파일의 시트 구성에 포함되어 있지 않아 구현하지 않았습니다.
- 영향력·감응도계수는 생산유발계수행렬의 열합·행합을 전체 산업 평균으로 정규화해 계산합니다.
- 대시보드와 분석은 선택한 산업분류별 파일에서 계산되며, 서로 다른 분류의 산업을 코드만으로 직접 비교하지 않습니다.
- 첫 실행에는 외부 CDN에서 Pyodide 및 패키지를 내려받아야 합니다.
- 브라우저 통합 테스트는 배포 환경에서 별도로 수행해야 합니다.
