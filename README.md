# 산업연관표(2023) 분석 대시보드

한국은행 2023년 산업연관표 자료를 활용하는 정적 웹 대시보드입니다.

## 이번 화면 개선
- 왼쪽 분석 목차를 요약 → 원자료 탐색 → 유발계수 → 영향력·감응도계수 → 유발효과 → 최종수요 비중 → 시나리오 분석 → 분석 안내 순서로 통합
- 핵심 산업구조 지표는 기본적으로 1위 산업을 표시하고, 상위 10개·20개 버튼으로 가로 막대그래프를 확장
- 영향력·감응도 파이프라인의 굵기 차이를 더 크게 표현하고 오른쪽 끝에 전방 → 후방 방향 화살표 추가
- 최종수요 비중을 비중 내림차순 가로 막대그래프로 변경

## 실행
정적 파일을 웹 서버 또는 GitHub Pages에 배포하면 됩니다. `index.html`을 브라우저에서 직접 열 경우 브라우저 정책에 따라 Worker/데이터 로딩이 제한될 수 있으므로 로컬 웹 서버 사용을 권장합니다.

## 자료
`data/` 폴더의 2023년 산업연관표 Excel 파일을 사용합니다. 원자료 출처와 기준 연도는 각 화면에 표시됩니다.

## v4 추가 기능: 전체 평균 기준선 및 산업 간 분석
- 산업 요약의 6개 순위표에 해당 지표의 전체 산업 산술평균 기준선을 점선으로 표시합니다.
- 유발계수는 생산·수입·부가가치 지표별 전체 산업 평균을 각각 별도 기준선으로 비교합니다.
- 영향력·감응도계수는 평균 1을 기준선으로 표시합니다.
- 유발효과 히트맵 하단에 생산·수입·부가가치 유발계수의 전체 산업 평균 행을 추가합니다.
- 시나리오 결과 막대그래프와 산업별 결과표에 전체 산업 평균을 표시합니다.
- 시나리오 분석 뒤에 2~3개 산업의 유발계수·영향력·감응도계수를 비교하는 기능을 추가했습니다.
- 선택 산업을 중심으로 주요 공급 산업(후방)과 주요 수요 산업(전방)을 보여주는 연결관계도를 추가했습니다.
- 평균 기준선은 현재 선택한 산업분류(대·중·소·기본부문)의 전체 산업을 기준으로 다시 계산됩니다.


## v5 화면 구조 및 평균 표시 개선
- 전체 평균 표시를 점선 대신 빨간색 체크(✓)로 통일하고, 화면 상단에 `* 빨간색 체크 표시: 전체 평균` 안내를 추가했습니다.
- 산업 요약 순위 버튼에 `상위 1개`를 추가하고 기본 선택으로 설정했습니다.
- 분석 화면을 네 개의 주 페이지로 재구성했습니다: `요약`(원자료 탐색 포함), `유발효과`, `시나리오 분석`, `분석 안내`.
- `유발효과` 페이지의 소목차는 `영향력·감응도계수`, `유발계수`, `최종수요 비중`으로 정리했습니다. 기존 02 유발계수와 04 유발효과(히트맵)를 하나의 `유발계수` 소목차 아래에 통합했습니다.
- `시나리오 분석` 페이지의 소목차는 `수요충격 변화 시나리오`, `산업 간 계수 비교`로 구성했습니다.
- 산업 간 연결관계도를 시나리오 분석에서 이동해 영향력·감응도계수 파이프라인 바로 아래에 배치했습니다.
- 연결계수는 별도 독립 지표가 아니라 레온티에프 역행렬 `L=(I−Ad)⁻¹`의 원소인 생산유발계수로 정의했습니다. `Lᵢⱼ`는 j산업의 국산 최종수요 1단위가 i산업의 생산을 직·간접적으로 유발하는 크기(배)이며, 선택 산업의 열은 후방 공급 연관, 행은 전방 수요 연관을 나타냅니다. 직접 거래액이나 단순 투입비율과는 구분됩니다.


## v6 목차 및 연결관계 설명 보완
- 평균 기준 표시를 빨간색 체크(✓)로 통일하고, 상단 안내 문구를 `* 빨간색 체크 표시 = 전체 평균`으로 정리했습니다.
- 왼쪽 목차는 4개 주 페이지(요약, 유발효과, 시나리오 분석, 분석 안내)로 구성합니다. 요약 페이지에는 원자료 탐색이 함께 들어갑니다.
- 유발효과 하위 목차는 영향력·감응도계수, 유발계수(기존 유발계수와 유발효과 히트맵 통합), 최종수요 비중으로 구성합니다.
- 시나리오 분석 하위 목차는 수요충격 변화 시나리오와 산업 간 계수 비교입니다.
- 산업 간 연결관계도는 영향력·감응도계수 하위에 두고, 전·후방 연쇄효과 파이프라인 바로 아래에 배치합니다.
- 연결계수는 국산 레온티에프 역행렬 `L=(I−Aᵈ)⁻¹`의 원소 `Lᵢⱼ`로 정의합니다. `Lᵢⱼ`는 j산업의 국산 최종수요 1단위 증가가 i산업의 생산을 직·간접적으로 유발하는 크기(배)입니다. 선택 산업의 열은 후방·공급 연관, 행은 전방·수요 연관을 나타냅니다.
